# Security

teamrig runs commands, guards a session's tool calls and holds GitHub tokens, so a weakness in it can reach what a
session may touch.

## Reporting a problem

Report a vulnerability privately, through a GitHub security advisory on this repository: **Security**, then
**Report a vulnerability** (the issue chooser links it too). Never open a public issue or pull request for it, and
leave out any real token, key or private path from what you send.

Say what an attacker can do, the version (`teamrig --version`), the OS and the steps that show it. A maintainer
answers in the advisory, and the fix ships with a note in its version.

## Supported versions

Only the newest version gets fixes: upgrade before you report.
